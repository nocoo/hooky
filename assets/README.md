# Asset locations

`brand/` contains the adopted original identity. Keep those bytes unchanged.

The English listing and existing screenshot/banner filenames in this directory are compatibility copies generated by `bun run materials`. Edit the inputs in [`materials/source/`](../materials/source/) and use the versioned [submission gallery](../materials/2.0.0/index.html) for uploads. New layouts, marquee alternatives, website, ZIP, and verification records live there.

The other language listing files are retained legacy copy; this 2.0.0 campaign was prepared and reviewed in English only. Runtime translations still cover all 10 supported languages.
