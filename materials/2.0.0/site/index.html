Read the privacy policy ↗

Where does my data go?

Templates, rules, and settings stay in local browser storage. When you send, the configured parameters go to your webhook endpoint. The publisher does not receive, proxy, or log those requests. The receiving service controls the data after delivery.

What kinds of endpoints work?

Use a webhook or automation endpoint that accepts your chosen method and parameters. GET and DELETE use query parameters; POST, PUT, and PATCH send a flat JSON object with string values. Custom HTTP headers are not supported.

Do rules send automatically as I browse?

No. Quick Send evaluates rules when you click the Hooky toolbar icon. The first enabled matching rule with a valid template sends. Otherwise, the popup opens.

Which page data can I use?

URL, title, selected text, description metadata, and Open Graph title, description, and image URL. Missing values become empty strings. Hooky does not extract the complete page body.

Which languages and themes are available?

Light, dark, and system themes. English, Simplified Chinese, Traditional Chinese, Japanese, Korean, French, German, Spanish, Brazilian Portuguese, and Russian. The interface follows Chrome's language.
