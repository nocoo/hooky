Hooky — Your page. In motion.

Send a link to your reading list, capture a selection for your knowledge system, or trigger your own workflow without leaving Chrome. You choose the webhook. Hooky brings the page context.

WHAT'S NEW IN 2.1

Clearer feedback comes to every send: the popup, Quick Send, and the right-click menu share request states, persistent toolbar badges, and a latest-result panel for the browser session. Page feedback makes results easier to notice. Open the panel or latest result without triggering another Quick Send rule. Identical requests already in progress share one send.

Configure advanced capabilities separately for each webhook: custom request headers, a send UUID, a small response receipt, JSON fields and a business success condition, and a warning for recently completed duplicate requests. These options stay off until configured.

MAKE A TEMPLATE. USE IT AGAIN.

Save a name, endpoint, HTTP method, and key-value parameters. GET and DELETE use query parameters; POST, PUT, and PATCH send a JSON object with string values. Review the request before sending.

Optional headers support Authorization, X-API-Key, and Idempotency-Key. Values stay masked in previews. Content-Type remains application/json; browser-managed headers cannot be overridden. Requests with custom headers do not follow redirects.

BRING THE PAGE WITH YOU

Use these variables in parameter or header values:

• {{page.url}} — page URL
• {{page.title}} — page title
• {{page.selection}} — selected text
• {{page.meta.description}} — description metadata
• {{page.meta.og:title}} — Open Graph title
• {{page.meta.og:description}} — Open Graph description
• {{page.meta.og:image}} — Open Graph image URL
• {{send.id}} — one UUID shared by the headers and parameters of a logical send

Review resolved values in the popup. Type or paste multiline notes without changing the saved template. Edited text keeps whitespace, line breaks, and literal {{...}} syntax. Paste from clipboard fills the selected value after you grant optional permission; ordinary manual paste needs no extension clipboard permission. Pasting never sends automatically.

KNOW WHAT THE RECEIVER SAID

Optional response reading retains up to 8 KiB of text or JSON, for up to 3 seconds after HTTP headers arrive. Receipts appear as plain text only inside Hooky and last for the browser session. Map JSON message and receipt fields or require an exact JSON scalar value as a business success condition.

HTTP success alone does not prove durable storage. Lost responses remain unconfirmed; Hooky does not retry automatically. A send UUID enables receiver-supported idempotency; the receiver must implement it.

Completed duplicate protection is optional per webhook, with a 1–300 second window. A repeated request shows the previous result. Review the held capture and choose Send anyway to send it again with a new UUID. The capture is available briefly in background memory and disappears when the worker stops.

ONE CLICK WHEN THE PAGE MATCHES

Quick Send rules choose a template on your toolbar click. Match page URL or title using contains, equals, starts with, ends with, or a regular expression. Matching ignores case. Enable or disable rules, test a sample, and set priority. The first enabled matching rule with a valid template sends; otherwise the popup opens. Rules do not send automatically as you browse.

Templates also appear in the Hooky context menu. Choose one to send page context or selected text. Optionally enable desktop notifications for errors and unconfirmed outcomes, or for all results. Notifications show only the template name and generic status.

SMALL BY DESIGN

Native JavaScript and local assets. No account, analytics, publisher relay, or cloud sync. Templates, headers, rules, and preferences stay in local browser storage. Page context is read on demand; requests go to your endpoint. Session results and opted-in receipts clear when Chrome clears the extension session. The receiving service controls data after delivery.

SET UP IN A MINUTE

1. Open Settings and create a webhook template.
2. Enter your endpoint, method, and parameters.
3. Add page variables and any optional endpoint settings, then save.
4. Open a webpage, review the values, and send.

You provide a compatible webhook or automation endpoint. Hooky does not provide service accounts or full-page text extraction.

Available in English, Simplified Chinese, Traditional Chinese, Japanese, Korean, French, German, Spanish, Brazilian Portuguese, and Russian. The interface follows Chrome's language. Requires Chrome 127 or later. Existing templates and rules remain compatible.
