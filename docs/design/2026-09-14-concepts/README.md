# Hooky × R2Shot · UI 概念研究

用 Chrome 打开 [index.html](index.html)。无需安装、构建或启动服务器。HTML、CSS、JS 与两枚图标放在同一目录即可离线使用。

这是实施前的独立概念稿；归档时保留当时的页面、交互和研究结论。

## 如何体验

- 顶部切换 **A / 柔光**、**B / 轻线**，比较阴影、边框、圆角与侧栏状态；切换紧凑 / 舒适密度和深浅色。
- 双应用视图同时展示两款插件的工具栏弹窗和设置页。点击「展开查看」，以 1120px 的工作台查看单个应用。弹窗在桌面上保持 360px 实际宽度。
- Hooky：修改模板、添加参数、点击变量插入、保存后在弹窗发送。发送结果中可检查这一次的请求。到快捷规则中尝试修改、启停、排序与试跑。
- R2Shot：粘贴带 bucket 的 S3 地址，查看自动拆分；测试连接、保存配置；切换可见区域 / 整页，调整画质与上限，模拟截图后复制链接。
- 每款弹窗上方可以切换正常、失败、未配置场景。切到「未配置」会清空该应用的演示配置。顶部「编辑示例网页」会更新两个应用的页面上下文。
- 外观页的浅色 / 深色 / 跟随系统分别影响各自的应用。刷新或「重置演示」恢复示例数据。

## 基于当前源码的功能梳理

| 应用 | 已有功能 | 概念稿中的对应空间 |
| --- | --- | --- |
| Hooky v1.1.1 | 多模板；名称、URL、HTTP 方法、键值参数 | 144px 侧栏 + 紧凑模板编辑器；方法与地址合为一行 |
| Hooky | 7 种页面变量；弹窗中编辑已解析的参数 | 可点击的变量标签；解析预览；可直接编辑的发送参数 |
| Hooky | GET / DELETE 使用查询参数；POST / PUT / PATCH 使用 JSON；无自定义请求头 | 请求预览随方法切换；不增加请求头编辑器 |
| Hooky | URL / 标题，包含、等于、开头、结尾、正则匹配；按顺序取第一条启用的匹配规则 | 折叠规则行与原位编辑；未命中时明确回到弹窗 |
| Hooky | 页面、选区、链接、图片右键调用；按需获取网页上下文 | 不新增独立右键菜单页面；复用同一模板与发送路径 |
| R2Shot v1.3.1 | 可见区域 / 整页截图；截图后上传、复制 URL、重试 | 范围分段控件、单一主操作、原位结果与失败反馈 |
| R2Shot | Endpoint、Access Key ID、Secret Access Key、bucket、公开域名；地址拆分与连接测试 | 同页分组、两列相关字段、密钥显隐、分享路径示例 |
| R2Shot | JPEG 质量 1–100，默认 90；整页上限 1–100 屏，默认 5 | 「截图设置」分组；原生 range + number，保存后同步弹窗 |
| R2Shot | UTC 日期目录 + UUID 文件名，HeadBucket 连接测试 | 示例链接保持该结构；连接与公开链接验证的含义分开 |
| 两者 | 系统 / 浅色 / 深色主题，本地配置 | 相同组件几何、独立色彩变量与独立主题 |

主要研究文件：两个仓库的 README、Manifest、popup、options / settings、Hooky 的 template / params / rules / quicksend / store，以及 R2Shot 的 r2-config / connection / storage / use-capture。

## 两个视觉方向

| | A / 柔光 | B / 轻线 |
| --- | --- | --- |
| 容器 | 12px 圆角，细边框与浅层阴影 | 6px 圆角，更明确的细线分隔 |
| 选中状态 | 轻微带色的表面与小面积强调 | 侧栏边缘色标、清楚的轮廓 |
| 气质 | 安静、柔和的日常工具 | 直接、紧密的工作工具 |

Hooky 使用紫藤色，R2Shot 使用海玻璃色。主按钮颜色比原始品牌浅色更深，以便白色文字清楚可读。两款应用共用系统字体、字号层级、控件、焦点状态与布局规则；原始章鱼和海豚图标保持透明背景，没有重绘或裁切。

工作台采用原生 CSS subgrid 对齐两列，使弹窗的内容变化不会造成下方设置页错位。表单区域内部滚动，保存操作始终留在底部。紧凑模式控件 32px，舒适模式 38px。

## 实际交互与模拟边界

表单编辑、输入校验、模板增删、7 种变量解析、5 种请求方法、5 种匹配条件、规则排序、主题、地址拆分与复制调用均由原生 JS 执行。

当前普通 HTML 没有扩展权限，所以网页上下文、截图、网络发送、R2 上传与连接测试为本地演示。截图中的小网页是 CSS 绘制的范围示意，并非实际抓取。上传链接使用示例域名，不指向已上传的图片。修改只保留在当前页面内存中。

请求预览、规则试跑 / 排序、截图示意与设置分组属于设计提案。没有加入云图库、历史中心、账号系统，也没有迁移 R2Shot 的现有 React 实现。

## 资源与验证

运行文件只有 `index.html`、`ui.css`、`ui.js` 和 `assets/` 中的两枚 64px 原始图标。没有框架、组件库、远程字体、CDN、后台轮询或持续动画。动画仅用于有限时长的演示操作，并遵循减少动态效果的系统设置。

脚本使用独立本地文件，没有内联事件、eval 或远程代码。页面 CSP 禁止网络连接；正式落地时，需要把模拟动作接回原有的 Chrome 与网络 API，并使用扩展自己的 Manifest 配置。

`check.cjs` 使用 Hooky 已安装的开发依赖 Puppeteer，在独立的无头 Chrome 中检查交互和布局，不属于页面运行资源：

```sh
node check.cjs
```

检查记录见 [check-results.json](check-results.json)。覆盖模板和变量、请求预览与发送结果、规则优先级、连接配置、数值范围、首次配置、剪贴板拒绝时的反馈、独立主题，以及 360–1920px 宽度下的主要页面。剪贴板 API 在自动检查中使用隔离替身，避免覆盖系统剪贴板。
