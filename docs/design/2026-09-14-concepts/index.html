DESIGN NOTES / 01

小界面的共同语言

依据 Hooky v1.1.1 与 R2Shot v1.3.1 当前源码整理。两种方向共享功能和布局，可在顶部直接切换。

A / 柔光

带少量色温的侧栏，细边框、低扩散阴影和 12px 容器圆角。适合轻巧、安静的日常工具。

B / 轻线

6px 容器圆角、更清晰的分隔线、平面层级和边缘色标。适合密集、直接的工具界面。

密度
紧凑控件 32px / 舒适控件 38px；弹窗宽 360px，以原始尺寸展示。
字体
系统 UI 字体 + 系统等宽字体；正文 13px，辅助文字 11–12px。
颜色
Hooky 使用紫藤色，R2Shot 使用海玻璃色；分别支持浅色、深色与跟随系统。
交互
原生表单、range、select、details 和 dialog；保留键盘焦点与明确的状态文字。

现有功能与设计探索

保留模板 CRUD、7 种页面变量、5 种请求方法、5 种规则条件，以及截图范围、R2 配置、质量和整页上限。

本稿新增的请求预览、规则试跑与排序、原位截图结果示意属于设计提案。没有增加云端图库、历史中心或账号系统。

运行方式

全本地 HTML / CSS / 原生 JavaScript，无框架、无外部字体、无网络请求。JS 为本地独立文件，不使用内联事件或 eval。图片沿用两个项目的透明原始图标。

发送、截图、上传和连接测试均为模拟；演示 URL 使用 example.com。保存修改只影响当前页面，刷新或重置可恢复。
